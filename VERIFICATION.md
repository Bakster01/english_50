# Проверка первой версии

- 50 фраз, пропуски в субтитрах сверены в плеере (SOURCE.md).
- Тесты проверяют интервалы 1/3/7/14 дней, раздельные навыки, досрочные занятия, сохранение ошибок, ограниченные повторы, повреждённое хранилище и неоднозначные варианты.
- Проверены отмена выхода и повторное открытие раскрытого ответа.
- В браузере с шириной 390 px пройдено занятие из пяти фраз: ознакомление, выбор перевода, выбор ситуации и вспоминание. Намеренные ошибки вернулись в очередь; итог 15/17, две фразы к повторению.
- Английский голос в проверочном встроенном браузере отсутствует: показывается объяснение. Звук на физическом Android ещё не проверен.
- Независимая проверка кода нашла два существенных замечания: ошибки досрочной практики не сохранялись; оставались семантически близкие варианты ответа. Оба исправлены и покрыты тестами.

Решения реализации: статический сайт без сборки и сервера данных; синтез речи устройства; размещение с доступом только владельцу. Существующий репозиторий не затрагивался. Незначительных отложенных замечаний проверки кода нет.
