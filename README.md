# Скажи — 50 английских фраз

Основной репозиторий: https://github.com/Bakster01/english_50

Рабочий тренажёр: https://english-fifty-phrases-gena.bakster01.chatgpt.site (вход через аккаунт владельца в ChatGPT). Изменения в GitHub сами по себе не публикуют новую версию Sites.

Мобильный тренажёр по ролику LinguaTrip TV: прослушивание и повторение, перевод на слух, выбор реплики по ситуации, самостоятельное вспоминание.

## Локальный запуск

Из этой папки: `node server.mjs`, затем открыть http://127.0.0.1:4173.

## Проверка

`node --test --test-isolation=none tests/app.test.mjs tests/core.test.mjs`

Нет зависимостей и сборки. Файлы для публикации находятся в `dist/`.

## Ограничения

Прогресс хранится в localStorage этого браузера, без синхронизации. Озвучка использует английский голос устройства; доступность, качество и необходимость интернета зависят от браузера и установленного голоса. Автоматической оценки произношения и записи микрофона нет. Проверка при ширине 390 px не заменяет проверку звука на реальном Android.

Формулировки, пропущенные в субтитрах, сверены с надписями в видео; сведения в SOURCE.md. Тексты переводов и заданий адаптированы.
